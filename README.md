# 🎮 MVC Character Selection & Spawning System

This project is a practical implementation of the **MVC (Model-View-Controller)** design pattern in Unity. It features a simple yet structured setup for **character selection, player spawning and management**, and **basic enemy spawning**.

The goal of this project was to deeply understand and apply the MVC architecture in a game development context.

<br><br>


## 🕹️ Features


### ✅ Character Selection
- Simple UI to choose a character.
- Selection logic handled via the **Controller**.
- Updates the selected player model and view accordingly.
<br><br>

### 🧍 Player Spawning
- Once selected, the player spawns at a predefined location.
- Uses **PlayerModel** to store data (e.g., selected character).
- **PlayerView** handles visuals.
- **PlayerController** manages player lifecycle.
<br><br>

### 🔴 Enemy Spawning (Basic)
- Red cubes (representing enemies) are spawned at random among 4 predefined spawn points.
- Though simpler, the enemy system follows the same **MVC principles** as the player.
